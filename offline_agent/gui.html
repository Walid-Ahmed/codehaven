Understands your code. Works offline.

Offline by designYour code never leaves this computer. No internet, no API fees, and CodeHaven never changes your files.

Repository

Choose a folder, then index it to start chatting.

Or a GitHub repository

Downloads the latest version once; after that it opens offline from this computer. Nothing of yours is uploaded. Private repositories work only if git here is already signed in to GitHub: CodeHaven never asks for your password.

Or a single file

No folder needed: pick or drop one text file (up to 64 KB), or a picture of code such as a screenshot (PNG or JPEG, up to 8 MB), which is read into a file you can save. It stays on this computer, and the copy CodeHaven reads is deleted when you open something else.
